Fit31 — готовый статический PWA-сайт.

1. Распакуйте ZIP.
2. Для локальной проверки в папке Fit31 выполните: python -m http.server 8080
3. Откройте http://localhost:8080 на компьютере.
4. Для использования на телефоне загрузите СОДЕРЖИМОЕ папки Fit31 на любой статический HTTPS-хостинг (например, Netlify Drop или GitHub Pages).
5. Откройте HTTPS-ссылку на телефоне, затем в меню браузера выберите «Добавить на главный экран».
6. Один раз откройте приложение онлайн, затем проверьте в авиарежиме.

Прогресс хранится в localStorage текущего браузера и не синхронизируется между устройствами. Регулярно экспортируйте резервную копию в Настройках.

Важно: иллюстрации упражнений пока не включены. Инструкции и назначения взяты из исходного Word/JSON. Приложение не заменяет профессиональную оценку нагрузки и техники.
